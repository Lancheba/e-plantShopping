# Paradise Nursery – e-plantShopping

Paradise Nursery is an online plant shop built with React and Redux Toolkit. Browse house plants by category, add them to your cart, and manage quantities and totals.

## Features
- Landing page with a **Get Started** button
- Navbar with links to Plants, Cart, and a live cart item count
- Plant cards (image, name, description, cost, Add to Cart) in three categories
- Cart page with quantity +/- buttons, Delete, per-item subtotal, and total cost
- Continue Shopping and Checkout buttons

## Run locally
```
npm install
npm run dev
```
